# Reabasto AI

Probabilistic replenishment planning for grocery retail: quantile demand forecast,
order-up-to policy, LLM-written explanations behind a numeric guardrail, and human
approval with an audit trail. See [docs/PLAN.md](docs/PLAN.md) for the full plan.
